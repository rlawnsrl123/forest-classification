# 실험 기록 — 공간 모델은 지역 간 탄소 오차 쏠림을 푸는가

작성 2026-09-21 · 데이터 3지역 20밴드 tif + 임상도 래스터 · RTX 5090
**모든 수치는 실측 출력이다. 2차 요약본에서 옮기지 말 것.**

---

## 0. 세 줄 요약

1. **공간 모델로 바꿔도 지역 간 쏠림은 그대로다.** U-Net 지역 간 |순오차| **3.25 ±0.94**,
   RF **3.19 ±0.03**. 구조를 아예 갈아도 오차가 안 줄었다.
2. **라벨 없이 대상 지역 통계만 다시 재면(AdaBN) 절반으로 준다.** 3.25 → **1.68 ±0.40**,
   지역 간 macro F1 0.468 → **0.520**. 시드 3개 전부 같은 방향.
3. **평가셋 교락을 제거하니 "전이 시 4배"가 2.3배가 된다.** 지역 간은 거의 그대로인데
   (3.05 → 3.19) **지역 내만 두 배로 커진다**(0.67 → 1.40).

> **α에 주는 의미**: 문서의 "모델 용량으로 안 된다(0.33%p vs 6.7%p)"보다 강한 버전이다.
> 용량이 아니라 **구조를 바꿔도** 안 된다. 그리고 라벨 없는 보정은 작동한다.
> → **모델로 풀 문제가 아니라 보정으로 풀 문제**라는 α의 전제가 독립적으로 지지된다.

### 1-2. 38피처 생성 규칙 [역추적 확정]

대전만 20밴드 tif와 준기 님 `feats38.npy` 를 **둘 다** 갖고 있다. 후보를 계산해 맞춰
규칙을 복원했다(`verify_feats.py`).

```
0~19   원 밴드 (여름 6~9월 10개 + 낙엽기 11~2월 10개,
                각 B2,B3,B4,B5,B6,B7,B8,B8A,B11,B12)
20~25  s_ndvi, w_ndvi, s_ndmi, w_ndmi, dNDVI(여름−낙엽기), dNDMI(여름−낙엽기)
26~37  (s_ndvi, w_ndvi, dNDVI) × 윈도우(5,15) × (평균, 표준편차)
```

**대조 결과**: 윈도우 반경(7px) 안쪽 유효 픽셀에서 **전 피처 최대 절대차 0.00049**
(float16 해상도). 차이 > 0.005 인 픽셀 **0.0000%**. 어긋나는 것은 영상 테두리 7픽셀뿐이고
유효 픽셀 1,029,600개 중 86개다.

부수 확인:
- **`W_NDVI = 21` 확정** — 피처[21] 중앙값이 대전 침엽 0.656 / 활엽 0.440 (문서 0.655 / 0.440)
- 문서 `03-[17]` 이 판별력 상위로 꼽은 **[32]·[36]** 의 정체가 밝혀졌다:
  `w_ndvi_w15_mean`, `dNDVI_w15_mean`. **"[36]은 부호 반대"** 라는 기술과도 맞는다 —
  dNDVI = 여름 − 낙엽기이므로 낙엽기 NDVI가 커질수록 작아진다

세 지역을 **같은 코드 경로**(`build_feats38.py`)로 다시 만들어 썼다. 9칸 비교의 전제다.

## 3. RF 9칸 [확정, 시드 3개]

### 3-1. 문서 `03-[7]` 과 대조 — 탄소 순오차(%)

| 조합 | 문서 | **우리 (교락 제거)** |
|---|---|---|
| **sun→hon** | **+5.92** | **+5.67** |
| hon→sun | −3.48 | **−3.41** |
| sun→dae | +3.12 | **+3.55** |
| dae→hon | +2.73 | **+3.73** |
| dae→sun | −1.57 | **−2.63** |
| sun→sun | +0.84 | **+1.36** |
| hon→hon | +0.12 | **+1.55** |
| hon→dae | −1.51 | **+0.12** |
| dae→dae | −1.05 | **+1.30** |

**큰 값은 그대로 재현된다.** 부호가 뒤집힌 두 칸(hon→dae, dae→dae)은 둘 다 절댓값이
작아 평가셋 구성에 민감한 칸이다. 9칸 중 7칸, 지역 간 6칸 중 5칸 부호 일치.

### 3-2. ★ "배율 보류"에 대한 실측 답

문서는 **"전이 시 탄소 오차 4배"를 보류**했다. 지역 내 기준선이 인접 타일 덕을 보고
있어서다(`01-[U]`: 대전 안에서 평가 영역만 공간 분리해도 오차 10배).

| | 지역 내 \|순오차\| | 지역 간 \|순오차\| | 배율 |
|---|---|---|---|
| 문서 RF (교락 있음) | 0.67 | 3.05 | **4.6배** |
| **우리 RF (교락 제거)** | **1.40 ±0.01** | **3.19 ±0.03** | **2.3배** |

> **지역 간은 거의 안 변하고(3.05 → 3.19) 지역 내만 두 배로 커진다(0.67 → 1.40).**
> 문서가 `[유도]` 로 적어둔 "보정 시 약 2.9배"와 같은 방향이고, 실측은 그보다 작다.
> → **"4배"는 쓰면 안 되고, 이 프로토콜에서는 2.3배다.**

macro F1도 같은 패턴이다. 지역 간은 문서와 거의 같은데(0.481~0.584 vs 문서 0.484~0.583)
**지역 내만 낮아졌다**(0.573~0.620 vs 문서 0.624~0.630).

## 4. ★ 본 질문 — 공간 모델에서도 쏠림이 남는가 [시드 3개]

| | 지역 내 \|순오차\| | **지역 간 \|순오차\|** | 지역 간 macro F1 |
|---|---|---|---|
| RF | 1.40 ±0.01 | **3.19 ±0.03** | 0.536 ±0.001 |
| **U-Net** | 0.84 ±0.12 | **3.25 ±0.94** | 0.468 ±0.016 |
| **U-Net + AdaBN** | 0.75 ±0.16 | **1.68 ±0.40** | 0.520 ±0.013 |

### 4-1. 답: 그대로 남는다

**U-Net 3.25 ±0.94 ≈ RF 3.19 ±0.03.** 픽셀 단위 RF를 128×128 패치를 보는 공간 모델로
바꿔도 지역 간 탄소 오차가 줄지 않았다.

문서에는 "모델 용량 2배로는 0.33%p, 학습 지역 교체는 6.7%p" 라는 결과가 있다.
이번 결과는 그것의 **강한 버전**이다 — 용량이 아니라 **구조를 바꿔도** 안 된다.

> 오프셋은 대기보정된 자료에 남는 **실제 분광 차이**이고, 그것이 만드는 계통 편향은
> 모델 구조로 흡수되지 않는다. **모델로 풀 문제가 아니라 보정으로 풀 문제다.**

### 4-2. AdaBN — 라벨 없는 보정은 작동한다

BatchNorm의 running 통계를 **평가 지역 영상으로 다시 잰다.** 가중치는 안 건드리고
라벨도 안 쓴다. 통계는 평가 지역의 **서쪽**(평가에 쓰지 않는 영역)에서 잰다.

| 시드 | 지역 간 \|순오차\| | 지역 간 macro F1 |
|---|---|---|
| 42 | 2.18 → **1.23** | 0.465 → **0.521** |
| 43 | 3.94 → **2.02** | 0.454 → **0.506** |
| 44 | 3.63 → **1.78** | 0.486 → **0.533** |
| **평균** | **3.25 → 1.68** (−48%) | **0.468 → 0.520** (+0.052) |

**시드 3개가 전부 같은 방향이고, 지역 내는 거의 안 변한다**(0.84 → 0.75).
즉 지역 내를 망가뜨리지 않고 지역 간만 고쳤다.

### 4-3. RF 정규화(1.9배 과보정)와의 대조 — 관찰

문서 `03-[16]`: 지역별 **입력 피처** 정규화는 6조합 전부 부호 반전, **평균 1.9배 과보정**.
이번 AdaBN: **과보정 없이 48% 감소.**

둘의 차이는 **보정을 어디서 하느냐**다. RF는 입력 단계에서 지역 중앙값을 빼서
"순천에 침엽이 많다"는 구성 정보까지 지웠다. AdaBN은 **학습된 표현 공간의 중간층**에서
정렬한다.

> ⚠️ **이건 관찰이지 규명이 아니다.** 왜 과보정이 안 났는지는 실험하지 않았다.
> 다음 실험: AdaBN 통계를 소스와 타깃 사이에서 **보간**해 α처럼 세기를 스캔한다.
> 준기 님 α 스캔과 직접 대응되는 구조다.

## 5. 말할 수 없는 것

- **"U-Net이 RF보다 낫다"** ❌ — macro F1은 U-Net이 전 구간에서 낮다
  (지역 간 0.468 vs 0.536, AdaBN 써도 0.520 < 0.536)
- **혼효림 천장 돌파** ❌ — 대전 동쪽에서 U-Net 혼효 F1 0.330 ±0.03, RF 0.355.
  차이가 U-Net SD 안이라 구별 불가. **"0.376 천장을 넘지 못했다"** 까지가 맞다
- **개별 칸 주장** ❌ — U-Net 칸별 시드 SD가 크다(dae→hon −2.48 ±4.27,
  sun→hon +3.54 ±3.18). **시드마다 부호가 뒤집히는 칸이 있다.** 총계로만 말할 것
- **"AdaBN 후에도 부호를 예측할 수 있다"** ❌ — AdaBN 후 문서 부호와 지역 간 6칸 중
  1칸만 일치. 오차가 작아지면서 부호가 흐트러졌다
- 지역 3개, 시드 3개. 확률 표본이 아니다

다르고, 실제로 홍천 지역 내 F1은 U-Net 0.635 ±0.02 로 RF 0.620과 거의 같다.

또한 이 비교는 "공간 모델 vs 비공간 모델"이 아니다 — **RF 입력 38피처에 이미 공간

→ 다음: U-Net에 0:26 피처만 주고 같은 비교를 한 번 더.

## 6. 중간에 잡은 버그 — 결과에 직접 영향

전부 U-Net 쪽에만 불리하게 작용하던 것들이다.

| 버그 | 증상 | 조치 |
|---|---|---|
| **입력 NaN** | feats38에 NaN 27,885픽셀(0.28%). 유효 라벨 픽셀엔 없지만 패치에는 딸려 들어옴. 컨볼루션으로 퍼지고 BatchNorm을 오염시켜 **가중치 수백만 개가 NaN** → 전부 침엽으로 예측하는 붕괴 | 표준화 뒤 `nan_to_num`, 밴드 통계도 NaN 제외 |
| **검증셋 누수** | 검증 패치를 서쪽에서 무작위로 뽑았는데 stride 64 < patch 128 이라 학습 패치와 50% 겹침 → 검증 F1 0.946 이 나와 **과적합이 안 보였다** | 검증을 **열 단위 띠**로 분리 |
| **경계 아티팩트** | 평가 시 패치를 겹치지 않게 이어붙여 U-Net이 약한 가장자리가 그대로 반영. RF엔 없는 불리함 | stride=patch/2 겹침 추론 + 해닝 창 가중. **대전 동쪽 F1 0.503 → 0.547** |
| **학습 영역 불일치** | RF는 서쪽 전체, U-Net은 학습 띠만 사용 — RF에 유리 | RF도 학습 띠로 제한. 대전 RF 0.608 → **0.601** |
| memmap pickle 복사 | Windows spawn 에서 워커마다 데이터 복사(홍천 3GB × 6) | `__getstate__` 로 핸들 제거 |
| 워커 난수 중복 | torch 가 numpy 전역 RNG 를 워커별로 안 갈아줌 → 증강이 전부 동일 | 워커별 RNG |

**과적합**: 검증 띠 F1이 step 500~1250 에서 최고, 이후 단조 하락(6000스텝에서 0.52).
검증 띠 없이 끝까지 돌린 첫 모델이 동쪽에서 0.547 에 그친 이유다. 현재는 최고 시점 복원.

## 8. 재현

```bash
# 38피처 생성 (세 지역 같은 코드 경로)
python build_feats38.py --s2-dir ../../data/s2 --out-dir ../../data/feats \
    --check-against "<준기님 daejeon_feats38.npy>"

python prepare_data.py --data-dir ../../data/feats --cache-dir ./cache --source feats38

# RF 9칸
python rf_9cell.py --cache-dir ./cache --seeds 3 --out rf_9cell.json

# U-Net 9칸 (지역별 학습 후)
python train_unet.py --region <region> --cache-dir ./cache --out ./runs \
    --base 16 --depth 3 --stride 32 --min-valid 0.10 --wd 1e-3 \
    --steps 4000 --val-col-frac 0.25 --val-every 250 --seed 42 --tag-suffix _B
python eval_9cell.py --cache-dir ./cache --runs ./runs --seed 42 --tag-suffix _B \
    --out unet_9cell.json
python eval_9cell.py --cache-dir ./cache --runs ./runs --seed 42 --tag-suffix _B \
    --adabn --out unet_9cell_adabn_s42.json

python summarize.py --rf rf_9cell.json --unet unet_9cell*.json --adabn unet_9cell_adabn_*.json
```

학습 1회 ≈ 2~4분, 9칸 평가 ≈ 3분 (RTX 5090). 전체 재현 ≈ 1시간.
