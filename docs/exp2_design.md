# 실험 2 설계 — α=0 LORO (기준 실험)

노트북: `files/05_loro.ipynb` · 작성: 7일차

## 목적

보정 없는(α=0) 전국 통합 RF가 **처음 보는 지역**에서 탄소 총량을 얼마나, 어느 방향으로 틀리는지 잰다.
논문의 "문제 제기" 부분이며, 결과에 따라 주장 범위(전국 / 시군)가 정해진다.

| 질문 | 실험 | 판단 |
|---|---|---|
| ① 전국 단위에 문제가 있나 | 실험 2 (이 문서) | 면적가중 합산 오차 > 기준이면 있음 |
| ② α로 고쳐지나 | 실험 3 | 보정 후 합산 오차 < 기준이면 고침 |

①이 작으면 α의 의미는 시군 단위 오차 감소로 좁혀진다. 이 경우 먼저 인정하고 쓴다.

## 구조 — LORO (Leave-One-Region-Out)

학습 8곳 중 1곳을 빼고 나머지 7곳으로 RF 학습 → 뺀 지역 평가. 8폴드 × 시드 5 = 40회.
라벨 없는 새 지역에 모델을 가져갔을 때를 흉내 낸다.

- 학습 8곳: 인제 · 홍천 · 강릉 · 평창 · 봉화 · 금산 · 거창 · 순천
- 대전(도시 파편화)·완도(상록활엽 41%)는 시험 지역 → 실험 2에 넣지 않음

## 데이터

지역 캐시 `outputs/{지역}_s05.npz` — 8곳 모두 같은 함수·같은 조건으로 생성.

- 유효 픽셀: 라벨 1–3 & 갱신년도 2024+ & **영상 유효(20밴드 합 > 0)** & **영상 결측에서 7px 이상**
  (결측 모서리 문제, 15×15 창 피처 오염 방지)
- 유효 픽셀 중 균등 무작위 최대 60만 (블록 1024, 패딩 16, seed 0)
- 전체 유효 픽셀 수 `n_total`을 함께 저장 → 면적가중에 사용
- S2 dtype 분기: int16 → /10000, float → 그대로 (대전만 float)

피처 38개 — `04_correction.ipynb`의 `make_feats` 그대로

| 번호 | 내용 |
|---|---|
| 0–19 | 반사율 (여름 6–9월 10밴드, 겨울 11–2월 10밴드: B2 B3 B4 B5 B6 B7 B8 B8A B11 B12) |
| 20–25 | NDVI·NDMI (여름, 겨울, 차이). NDVI = B8/B4, NDMI = B8/B11 |
| 26–37 | 여름·겨울·차이 NDVI의 5×5, 15×15 창 평균·표준편차 |

03/04용 기존 캐시 `{지역}_samples.npz`와 **섞지 않는다.**

## 모델

- RF: 80트리, `min_samples_leaf=20`, `max_features='sqrt'`, `class_weight='balanced'` (04와 동일)
- 학습 표본: 학습 지역당 3만 (7곳 합 21만), 지역 동일 가중
- 시드: 16, 17, 18, 19, 20
- 평가: 평가 지역 캐시 전체 (최대 60만)

## 지표

**탄소 오차 (부호 포함 %)** — 탄소계수 C = {침엽 79.25, 활엽 101.02, 혼효 92.01} tC/ha

```
오차 = (Σ 예측 클래스 탄소 − Σ 실제 클래스 탄소) / Σ 실제 클래스 탄소 × 100
```

**면적가중 합산 오차** — 지역 표본 탄소밀도에 지역 유효 산림 픽셀 수를 곱해 8곳을 더한 뒤 같은 식.
지역마다 부호가 다르면 합산에서 상쇄된다. 결과는 **지역별 / 합산 두 수준**으로 보고한다.

**평균밀도 기준선** — 분류 지도 없이 `학습 7곳 클래스 비율 × 탄소계수 × 평가 지역 산림 픽셀 수`.
이 기준선을 못 이기면 탄소 총량에는 분류 모델이 필요 없다는 뜻이 되므로 가장 먼저 확인한다.

**macro F1** — 참고용. F1 곡선은 평평하고 탄소 곡선은 가파르므로 F1로 보정량을 정하지 않는다.

## α 스윕 (실험 3용 — 실험 2에서는 저장만)

같은 RF로 α ∈ {0, 0.25, 0.4, 0.5, 0.6, 0.75, 1.0}의 예측도 저장한다. 실험 3에서 RF를 다시 학습할 필요가 없다.
평가 지역 피처만 학습 지역 통계 쪽으로 α만큼 옮긴다 (학습 쪽은 그대로).

```
med_α = α·med_학습 + (1−α)·med_평가
X'    = med_α + (X − med_평가) · (sd_학습 / sd_평가)^α
```

- med = 피처별 중앙값, sd = 피처별 표준편차. 학습 통계는 그 폴드의 학습 표본(7곳 합친 것)으로 계산
- α=0 원본, α=1 = 학습·평가 각자 표준화한 것과 동일 (RF는 피처별 단조 아핀 변환에 불변)
- α* = 탄소 오차가 0을 지나는 α (구간 선형 보간). 격자 [0, 1] 안에서 부호가 안 바뀌면 미검출
