## 1. 우리가 최종적으로 답하려는 질문

계획서 제목은 "산림 유형 분류 AI 모델 개발 및 성능 평가"지만,
실제 목표는 두 겹입니다.

> **위성영상으로 만든 산림 유형 지도가,
> 산림 LCA의 탄소축적량 산정에 쓸 수 있을 만큼 정확한가?**

앞부분(분류 모델)은 수단이고, 뒷부분(LCA 활용성)이 이 연구의 차별점입니다.
정확도만 보고하면 흔한 학부 프로젝트지만, "그래서 이 오차가 탄소량 추정에
얼마나 영향을 주는가"까지 가면 졸업논문이 됩니다.

---

## 2. 왜 탄소축적량이 등장하는가

계획서의 "LCA 산정에 필요한 산림 데이터로서의 활용 가능성을 검토한다"를
실제로 수행하려면 이 연결고리를 따라가야 합니다.

```
위성영상
   ↓  (AI 분류)
임상 유형 지도 (침엽 / 활엽 / 혼효)
   ↓  (픽셀 수 × 100m²)
임상별 면적 (ha)
   ↓  (국립산림과학원 임상별 탄소 계수 tC/ha)
탄소축적량 (tC)
   ↓
산림 LCA 입력값
```

산림 LCA에서 탄소 흡수·축적을 계산하려면 **임상별 면적**이 반드시 필요합니다.
그런데 그 면적을 위성으로 추정하면 분류 오차가 그대로 면적 오차가 되고,
계수를 곱하는 순간 탄소량 오차로 증폭됩니다.

**우리가 정량화할 것은 이 오차 전파입니다.**
"분류 정확도 85%"가 아니라 "탄소축적량 추정 오차 ±N%"까지 말하는 것.
이게 있어야 "LCA 입력으로 쓸 수 있는가"에 답한 게 됩니다.

## 3. 왜 이 순서로 진행했는가

각 단계에는 이유가 있습니다. 순서를 바꾸면 뒤에서 전부 다시 해야 합니다.

### 3-1. 대상 지역을 대전으로 시작한 이유 (파일럿)

전국이나 강원도로 바로 시작하면 파일이 수 GB라 Colab에서 다루기 어렵고,
파이프라인 버그를 찾는 데만 며칠 걸립니다.
대전은 작고, 학교가 있어 **현장 확인이 가능**하고, 도시-산림 경계가 뚜렷해
검증이 쉽습니다. 파이프라인을 여기서 완성하고 큰 지역으로 확장하는 전략.

**본 실험 지역은 아직 미정 — 팀 논의 필요 (5절 참고).**

### 3-2. 위성영상을 여름 + 낙엽기 두 시기로 만든 이유

침엽수와 활엽수는 **여름에는 둘 다 초록이라 구분이 거의 불가능**합니다.
겨울에 활엽수만 잎을 떨구기 때문에, 두 시기를 비교해야 신호가 생깁니다.

이 가설을 코드로 먼저 검증하고 나서 본격 작업에 들어갔습니다 (4-3 결과).

### 3-3. 임상도를 정답 라벨로 쓰는 이유

산림청이 항공사진 판독 + 현장조사로 만든 공식 도면이라 신뢰도가 높고,
1:5,000 축척이라 Sentinel-2 10m 해상도와 잘 맞습니다.
무료이고 전국이 있어 지역 확장도 쉽습니다.

### 3-4. 좌표계를 EPSG:5179로 통일한 이유

위성영상과 임상도가 다른 좌표계면 수십~수백 m 어긋납니다.
이 프로젝트에서 가장 사고가 잦은 지점입니다.
**GEE에서 내보낼 때 미리 임상도 좌표계로 맞춰서** 재투영 자체를 없앴습니다.

### 3-5. train/test를 지역·타일 단위로 나누는 이유 (중요)

픽셀을 랜덤으로 나누면 **바로 옆 픽셀이 학습셋에 들어가서 정확도가 부풀려집니다.**
심사에서 가장 많이 지적당하는 부분입니다.
그래서 처음부터 공간적으로 떨어진 단위로 분할하도록 설계했습니다.
이 때문에 본 실험 지역이 **최소 3곳, 서로 멀리 떨어져 있어야** 합니다.

## 4. 현재까지의 결과

### 4-1. 데이터 준비 완료

| 항목 | 상태 |
|---|---|
| GEE 계정 | 등록 완료 (커뮤니티 등급, 무료) |
| 위성영상 | 대전 20밴드 (여름10 + 낙엽기10), 10m, 683MB |
| 임상도 | 대전 2025년판, 폴리곤 18,908개 |
| 정답 라벨 | 위성 격자에 정렬 완료 |

### 4-2. 정합 검증 통과

위성영상과 임상도가 정확히 겹치는지 두 방법으로 확인:

- **육안**: 라벨 경계가 산 능선·계곡을 정확히 따라감
- **수치**: 임상도 면적 비율과 라벨 픽셀 비율이 소수점까지 일치

| 클래스 | 면적 비율 | 픽셀 비율 |
|---|---|---|
| 활엽수림 | 46.1% | 46.2% |
| 침엽수림 | 32.8% | 32.7% |
| 혼효림 | 17.1% | 17.1% |
| 비산림 | 4.0% | 4.0% |

클래스 균형이 좋아서 별도 불균형 처리가 거의 필요 없습니다.

### 4-3. 다시기 접근의 정당성 확인 (핵심 성과)

모델을 만들기 전에, 데이터에 신호가 실재하는지부터 검증했습니다.

클래스별 NDVI(식생 활력도) 중앙값:

| 클래스 | 여름 | 낙엽기 | 차이 |
|---|---|---|---|
| 침엽수림 | 0.852 | **0.646** | 0.198 |
| 혼효림 | 0.873 | **0.539** | 0.316 |
| 활엽수림 | 0.885 | **0.438** | 0.438 |

**읽는 법**

- 여름에는 세 클래스 차이가 0.033뿐 → 구분 거의 불가능
- 낙엽기에는 차이가 0.208 → **약 6배 잘 갈림**
- 침엽 > 혼효 > 활엽 순서가 물리적 예측과 정확히 일치
- 혼효림이 정확히 중간에 위치 → 임상도 라벨 품질이 좋다는 방증

**의미**: 다시기 영상을 쓰는 것이 옳았다는 정량적 근거를 확보했습니다.
여름 영상 하나만 썼다면 이 프로젝트는 실패했을 가능성이 큽니다.
이 표는 논문의 핵심 근거 중 하나가 됩니다.

### 4-4. 예상 못 했던 발견 — 임상도 라벨의 시의성 문제

"2025년 임상도"인데 폴리곤의 **26%가 2015년 조사분**이었습니다.

| 갱신년도 | 폴리곤 수 |
|---|---|
| 2025 | 5,641 |
| 2015 | **4,883** |
| 2024 | 4,193 |
| 미상 | 2,050 |

10년 사이 벌채·조림·산불이 있었다면 정답이 틀린 겁니다.
산림청도 "항공사진 촬영시기와 제작시점 차이로 현장과 불일치할 수 있다"고
공식 명시하고 있습니다.

**이건 사고가 아니라 논문 재료입니다.**
"라벨 갱신년도별 분류 정확도 비교"를 별도 실험으로 추가하면,
라벨 시의성이 LCA 데이터 신뢰도에 미치는 영향을 정량화할 수 있습니다.

## 5. 팀 논의가 필요한 사항

### ① 본 실험 지역 3곳 확정 (가장 시급)

이게 정해져야 다음 단계로 갑니다. 선정 기준:

- 임상 구성이 서로 다를 것
- 지리적으로 멀리 떨어져 있을 것 (3-5 이유)

현재 후보:

| | 지역 | 특성 |
|---|---|---|
| A | 강원 | 잣나무·낙엽송 조림지, 침엽 비율 최고, 고도차 큼 |
| B | 충남/대전 | 구릉지, 참나무 중심, 활엽·혼효 우세, 현장 접근 가능 |
| C | 전남 | 편백·삼나무 + 상록활엽, A와 가장 다름 |

**전남의 주의점**: 상록활엽수(가시나무, 후박나무 등)는 겨울에도 잎을 안 떨궈서
낙엽기 신호가 안 통합니다. 남부 지역 성능이 떨어질 수 있습니다.
- 논문 재료로 삼거나 (권장) — "남부 상록활엽수림에서 다시기 접근의 한계"
- 경상북도(소나무 우세)로 교체하거나

### ② 역할 분담

전공이 다르니 자연스럽게 나뉩니다.

| 담당 | 내용 |
|---|---|
| 모델링 | 분류 모델 설계·학습·평가, 성능 개선 |
| LCA·환경 | 탄소계수 조사, 면적→탄소량 변환, 환경적 해석 |
| 데이터·인프라 | 데이터 파이프라인, 지역 확장, 코드 관리 |

### ③ 목표 수준 합의

- 임상 3분류만 할 것인가, 우점 수종(소나무·참나무 등)까지 갈 것인가
  → 수종까지는 10m 해상도로 어려움. 3분류 권장
- 파운데이션 모델(Prithvi) 파인튜닝까지 갈 것인가
  → 계획서의 "파운데이션 모델" 문구와 연결되므로 권장하나 난이도 있음

## 6. 되돌리기 비용

방향을 바꾼다면 지금이 가장 쌉니다.

| 결정 | 바꾸는 비용 | 비고 |
|---|---|---|
| 대상 지역 | **낮음** | 코드에서 파일 경로만 교체. 재실행 몇 시간 |
| 클래스 체계 (3분류) | **낮음** | 매핑 테이블 한 줄 수정 |
| 위성 시기 조합 | **낮음** | 날짜 파라미터만 변경 |
| 데이터 소스 (Sentinel-2) | 중간 | 다른 위성으로 가면 파이프라인 재작성 |
| 정답 라벨 (임상도) | **높음** | 다른 라벨은 사실상 없음 |
| LCA 연결이라는 목표 | **높음** | 계획서·지도교수 승인 사항 |

즉 **지역·클래스·시기는 얼마든지 바꿔도 됩니다.**
지금까지 만든 파이프라인은 그대로 재사용됩니다.

## 8. 진행 상황 체크리스트

각 항목이 왜 필요한지 함께 적었습니다.

| 항목 | 상태 | 왜 필요한가 |
|---|---|---|
| GEE 등록 / 위성영상 합성 | 완료 | 입력 데이터(X) 확보 |
| 임상도 확보 / 구조 파악 | 완료 | 정답 라벨(y) 확보 |
| 라벨 래스터화 + 정합 검증 | 완료 | X와 y를 같은 격자에 정렬. 여기가 틀리면 이후 전부 무의미 |
| 다시기 신호 정량 확인 | 완료 | 연구 가설의 타당성 증명 |
| 공간 분할 | 예정 | 성능 부풀림 방지. 심사 방어의 핵심 |
| RF 베이스라인 | 예정 | 비교 기준선. 없으면 딥러닝 성능을 평가할 수 없음 |
| U-Net | 예정 | 픽셀 단위 분류 지도 생성 |
| Prithvi 파인튜닝 | 예정 | 계획서의 파운데이션 모델 요건 |
| 갱신년도별 정확도 비교 | 예정 | 라벨 시의성이 결과에 미치는 영향 정량화 |
| 밀도·영급별 오차 분석 | 예정 | "언제 틀리는가"를 밝혀 논문 고찰을 강화 |
| 탄소축적량 오차 분석 | 예정 | **최종 목표.** LCA 활용 가능성에 대한 답 |
