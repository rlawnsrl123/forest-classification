## 3. 판정과 해석

**판정 [확정]: 실패.** 사전 기록 그대로. 간이 방식은 누설로 낙관 쪽 치우침이 있는데도 실패했으므로 엄밀 방식(56폴드, 약 3시간)은 돌릴 이유가 약하다 [유도]

**원인 [유도 — 메커니즘, 일부 추정]**
- α를 올렸을 때 오차가 움직이는 **방향이 지역마다 반대**. 공통 α가 한 그룹은 고치고 다른 그룹은 망친다
- 두 그룹이 05 `[5]` 겨울 NDVI 중앙값으로 깔끔히 갈림: 악화 그룹 bong 0.632 / geoc 0.623 / sunc 0.657 / gang 0.536, 개선 그룹 inje 0.460 / hong 0.418 / pyeo 0.378 / geum 0.456
- shift는 평가 지역 값을 학습 통합 중앙값 쪽으로 끈다 → 겨울 NDVI 높은 지역은 아래로 끌려 활엽 예측 증가 → 탄소 증가(활엽 101 > 침엽 79). 봉화는 **실제로 침엽 60%**라 높은 것 → 보정이 진짜 숲 구성을 지움 (중앙값 차이에 실제 숲 구성 차이가 섞여 있다는 우려가 실현됨)
- n=8 사후 관찰. 결론이 아니라 실험 4의 가설

**말할 수 있는 것**
1. 전체 중앙값 기준의 라벨 없는 공통 α 보정은 8지역 LORO에서 시군 오차를 줄이지 못했다 [확정]
2. F1로는 이 문제가 안 보인다: 순천은 F1 0.555→0.605(+0.05)인데 탄소 오차 −1.36→+1.32로 방향 반전. 봉화는 F1 −0.017에 탄소 +1.8%p 악화 [확정]
3. α 자체(세기)가 아니라 **α가 끌어당기는 기준(전체 중앙값)**이 문제라는 해석 [유도]

**말할 수 없는 것**: 3일차 "84% 감소"(쌍별 설계)와 비교 불가. 원인이 겨울 NDVI 수준/구성이라는 것은 가설
