# 연구 지역

지역 간 전이 평가에 쓰는 10개 지역의 선정 근거와 데이터 특성.
코드: `files/02_regions.ipynb` (기존 3곳), `files/02b_add_regions.ipynb` (신규 7곳).
결과 파일(Drive `forest/data/`): `screen_result.csv`, `evergreen_old_regions.csv`, `export_log.csv`, `region_meta.csv`.

## 1. 구성

| 역할 | 지역 |
|---|---|
| 학습 (8) | 인제 · 홍천 · 강릉 · 평창 · 봉화 · 금산 · 거창 · 순천 |
| 시험 — 도시 파편화 | 대전 |
| 시험 — 적용 범위 밖 | 완도 (상록활엽 41%) |

## 2. 선정 원칙

1. **위도를 고르게** — 온대 북부·중부·남부에 걸쳐 34.2°–38.0°.
2. **위도와 함께 움직이는 요인을 분리** — 고도, 해안/내륙, 낙엽송 비율이 위도와 같은 순서로 변하지 않도록 엇갈리는 지역을 포함.
3. **라벨-영상 시기 불일치 지역 제외** — 2025년 3월 산불 피해 시군(의성·안동·청송·영양·영덕·산청·하동·울주)은 후보에서 제외. 라벨은 산불 전, 영상은 2024–2025.
4. **사전 확정 기준** (`screen()` 실행 전에 정함)
   - 학습 지역: 2024+ 라벨 픽셀 ≥ 600,000
   - 낙엽송 비율이 위도와 엇갈리는 지역 ≥ 1곳
   - 해안 지역 ≥ 1곳

- 침엽/활엽/혼효는 영상 결측 포함 래스터 집계(02b `[11]`)라 합이 위 값보다 0–1.6% 크다 (7절).

- 홍천 낙엽송%: 면적 기준 37.4%. 이전 기록의 33%는 03 노트북의 학습 샘플 기준이라 다르다. 이후 37.4% 사용.
- `screen()`(폴리곤 면적, export 전 추정)과 위 값의 차이는 0.0–0.1% — 사전 선별이 정확했다.

## 4. 선정 결과

| 기준 | 결과 |
|---|---|
| 학습 지역 ≥ 600,000 px | 6곳 모두 통과 (최소 금산 856,508) |
| 낙엽송–위도 엇갈림 | 통과 — 강릉(11.0%)이 같은 위도의 홍천(37.4%)의 1/3, 최북단 인제(19.0%) < 평창(45.8%), 금산(19.5%) > 더 북쪽의 대전(8.6%) |
| 해안 지역 | 강릉. 단 35 km 범위에 백두대간 산지가 포함돼 평균 고도 434 m — 해안·산지 혼합 |
| 고도–위도 분리 (추가 확인) | 평창(37.5°, 760 m)이 인제(38.0°, 622 m)보다 높고, 거창(35.7°)이 550 m |

완도는 2024+ 픽셀이 311,632로 600,000 미만이나 시험 전용이므로 기준 대상이 아니다.

### 상록활엽

- 학습 8곳 모두 ≤ 0.11% → 학습 데이터에 상록활엽수가 사실상 없다.
- 순천 0.11%(약 2,000 px, 20 ha)는 전부 오분류돼도 순천 탄소 총량의 약 0.03% — 무시.
- 완도는 2024+ 산림의 41.35%가 상록활엽(대부분 코드 60 기타상록활엽). 겨울 잎 유무로 침엽을 판단하는 모델이 학습 때 보지 못한 숲에서 어떻게 틀리는지 시험한다.
- 완도 전체 산림(모든 갱신년도)에서는 18.8% — 2024+ 갱신 구역이 상록림 쪽에 몰려 있다. 완도 결과는 "완도 전체"가 아니라 "상록활엽이 많은 조건"으로 해석한다.

## 5. 데이터 출처와 코드

- 임상도: 산림청 산림공간정보서비스(FGIS), **2025년 임상도(1:5,000), 시군구 단위**. 행정구역 단위로 받아야 `export_region`이 해당 시군 중심에서 범위를 자른다 (시도 단위로 받으면 도 전체의 중심을 자름).
- 사용 열: `FRTP_CD`(임상), `갱신년도`, `KOFTR_GROU`(수종그룹).
- 임상 → 라벨: 1 침엽 / 2 활엽 / 3 혼효 / 4 죽림 → 0(배경) / 0 비산림 → 0.
- 수종그룹 코드 (FGIS 코드 정의서 `DATA003_임상도(5000).pdf`)
  - 13 낙엽송 (잎갈나무, 일본잎갈)
  - **60–68 상록활엽** — 60 기타상록활엽, 61 가시나무류, 62 구실잣밤, 63 녹나무, 64 굴거리, 65 황칠, 66 사스레피, 67 후박, 68 새덕이
- **정정 (2026-10-02)**: 상록활엽을 61–68로 집계해 60(기타상록활엽)이 빠져 있었다. 완도가 0.44%로 나와 발견, 41.35%로 정정. 02 `[4]`의 상록활엽 폴리곤 수 출력도 같은 범위라 과소. 라벨·학습·평가에는 수종 코드를 쓰지 않으므로 실험 결과에는 영향 없음. "상록활엽 전국 0.17%"라는 이전 수치는 출처와 코드 범위 미확인 — 재확인 전 사용 금지.

## 7. 실험 코드 주의 — 영상 결측 모서리

GEE는 경위도 사각형을 EPSG:5179로 내보내며 감싸는 직사각형으로 저장한다. 라벨은 직사각형 전체에 칠해지지만 **영상은 원래 사각형 안에만 값이 있고 모서리는 0**.

| 지역 | 2024+ 숲 라벨 중 영상 없음 |
|---|---|
| 인제 · 평창 · 강릉 · 봉화 | 43,984 · 53,707 · 51,940 · 51,261 (1.2–1.6%) |
| 거창 · 완도 | 3,797 · 2,854 |
| 금산 · 대전 · 순천 | 0 |
| 홍천 | 80 |

→ 학습 샘플 추출과 평가 모두 유효 픽셀 조건에 **영상 값이 있을 것**(밴드 합 > 0)을 넣어야 한다. 빼지 않으면 값이 전부 0인 픽셀이 숲으로 학습·평가된다. 기존 3곳은 범위를 자르지 않아 이 문제가 없었다.
